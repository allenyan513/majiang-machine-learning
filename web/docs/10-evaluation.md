# 第 10 章 评估与诚实的失败

> 对应代码：`majiang/ml/compare.py`、`majiang/ml/plot.py`、[PR #3](https://github.com/allenyan513/majiang-machine-learning/pull/3)

这一章是整份教程里最重要的一章。前面九章教你怎么造东西，这一章教你怎么知道造出来的东西到底行不行——以及当它不行的时候，怎么读出原因。

## 结果先说

60 轮 PPO、6 万局自对局、15 分钟训练之后：

| | 均分 | 胜率 | 配对差值 vs 规则 bot |
|---|---|---|---|
| 规则 bot | −0.049 | 22.2% | — |
| 监督模型 | −0.065 | 21.9% | −0.015 ± 0.042 |
| RL 模型 | −0.070 | 21.8% | −0.021 ± 0.042 |

**没有超过老师。** 三者的差距全在置信区间内，统计上分不清谁强谁弱。

## 麻将评估的噪声有多大

在解释失败之前，得先建立一个基本认识：**麻将的单局结果几乎全是运气。**

我们的计分下，单局分数的标准差约 1.0。那么 n 局评估的标准误是 `1.0/√n`，95% 置信区间是 `±1.96/√n`：

| 局数 | 95% 区间 | 能分辨的差距 |
|---|---|---|
| 100 | ±0.196 | 几乎什么都分不出 |
| 1,000 | ±0.062 | 只能看出巨大差距 |
| 2,000 | ±0.044 | 勉强 |
| 10,000 | ±0.020 | 能看出中等差距 |
| 100,000 | ±0.006 | 够用 |

而我们想检测的改进是多少？一个"稍微聪明一点"的策略，均分提升可能就 0.02–0.05。**这意味着 2000 局的评估根本分辨不出我们关心的改进。**

这是所有棋牌 AI 项目的共同困境。真实麻将平台用 Elo 或稳定段位来解决，需要几万局。

### 位置效应：一个真实的混杂变量

我们还测了一件事：让 4 个**完全相同**的规则 bot 对打 4000 局，看各座位的均分。

```
总体 −0.021 ± 0.03   （无偏，符合预期）
庄下家 +0.05
庄上家 −0.08
```

同一个 agent，因为座位不同，均分差了 0.13——**比我们想检测的改进还大**。（庄下家有优势是麻将的已知现象：庄家先打牌，下家先获得吃碰机会。）

所以第 5 章的座位轮转不是可有可无的细节，它是实验有效性的前提。

## 配对评估：把方差压下去

标准评估里，每个候选各打各的牌局，方差来自两部分：牌运 + 策略差异。牌运的方差远大于策略差异，把信号淹没了。

**配对评估**（paired evaluation）的思路：让所有候选打**完全相同的牌局**——同样的 seed、同样的座位、同样的三个规则 bot 对手。然后比较逐局的**差值**。

```python
def _worker(args):
    name, seeds = args
    out = np.zeros((len(seeds), 3))  # score, win, deal_in
    for i, s in enumerate(seeds):
        seat = s % 4
        agents = [make_agent(name, s) if p == seat else RuleAgent() for p in range(4)]
        r = play_game(agents, seed=s, dealer=(s // 4) % 4)
        out[i] = (r.scores[seat], r.winner == seat, r.loser == seat)
    return out
```

统计上的收益：

```
Var(A - B) = Var(A) + Var(B) - 2·Cov(A, B)
```

因为两个候选面对同一副牌，它们的结果高度正相关，`Cov` 很大，差值的方差就小得多。**同一副牌两个策略打出同样结果的那些局，对差值的贡献是 0**——它们被自动抵消了。

报告时输出差值的置信区间：

```python
d = r[:, 0] - results[base][:, 0]
se = d.std(ddof=1) / np.sqrt(n)
line += f"   {d.mean():+.3f} ± {1.96 * se:.3f} (95%)"
```

```bash
uv run python -m majiang.ml.compare --candidates rule,nn:models/discard.pt,nn:models/rl.pt --n 2000
```

配对评估让 2000 局达到了独立评估一万局的分辨力。**任何比较两个策略的实验，都应该用配对设计。**

一个细节：多进程切分 seed 时是交错切的（`seeds[i::workers]`），结果要按 seed 顺序拼回去，否则配对就错位了：

```python
rows = np.zeros((n, 3))
for c, part in zip([c for c in chunks if c], parts):
    rows[[s - seed for s in c]] = part
```

## 从曲线里读失败

```bash
uv run python -m majiang.ml.plot models/rl_log.csv
```

四张图，读出三个信号。

### 信号一：评估分数在涨，但只是涨回原位

贪心评估胜率从 20% 爬到 23.5%，均分从 −0.08 到 −0.01。看起来在学习。

但对照一下：老师（规则 bot）的均分是 −0.049，四家打平的理论值约 −0.02（有流局所以略负）。所以这条曲线的真实含义是：**采样初期的策略因为随机性略低于老师，训练把它拉回了打平。** 不是超越，是恢复。

**教训：任何"上升曲线"都要和基线画在同一张图上。** 单看曲线在涨，很容易自我欺骗。我们的 `plot.py` 专门画了 y=0 和 y=0.25 的参考线：

```python
ax.axhline(0, color="k", lw=0.8, ls="--")
ax.set_title("均分（>0 = 超过规则 bot）")
```

### 信号二：价值损失全程不降

`value_loss` 稳定在 0.6 左右，60 轮没有下降趋势。

这说明 **critic 没学会预测终局结果**。想想它的任务有多难：看一个中局局面，预测这局最终得几分。而实际结果取决于后面 40 张牌的发牌顺序和三个对手的决策——**这件事的内在不确定性就很大**，V(s) 的理论最优值也只能是个平均，残差降不下去。

20 万样本对这个任务远远不够。而 critic 不准，优势估计 `A = G - V(s)` 就不准，PPO 的梯度方向就不可靠。

### 信号三：策略在动，分数不跟

策略熵从 0.33 降到 0.25（变自信了），对老师的 KL 从 0.003 涨到 0.085（跑出去了）。策略确实在变化，但评估分数没跟上。

**策略在变 + 分数没变 = 在学错的东西。**

## 根本原因：塑形奖励主导了学习

把三个信号连起来，结论很清楚。

我们的奖励有两部分：

1. **终局分数**：稀疏（每 60 步一次）、噪声大、但这是真正的目标
2. **塑形奖励**（向听数减少，系数 0.1）：稠密（每步都有）、噪声小

一局 60 步，每步塑形奖励约 0.1，累计量级和终局奖励（±1 到 ±3）相当。但塑形奖励的**信噪比高得多**——它是确定性的，直接由动作决定；而终局奖励要穿过 40 步的随机性。

梯度下降会走阻力最小的路：**优先优化塑形奖励。**

而"向听数下降得快"这个目标是什么？**正是规则 bot 自己的策略。** 我们用一个稠密信号，把学生往老师的方向推——那它的上限当然就是老师。

要超过老师，必须学到规则 bot 没有的东西：防守（第 5 章说过，它的防守只有一条弱启发式）、放弃追听、根据对手副露调整策略。**这些知识只存在于终局奖励里**，而终局奖励被塑形奖励盖住了。

这是一个经典的困境：塑形奖励解决了探索问题，但同时限制了能学到的上限。

## 下一步的三个方向

1. **降低塑形系数**（0.1 → 0.02）+ 加大每轮对局数 + 更多轮次。让终局信号占主导。风险：训练会慢很多，可能根本学不动
2. **改进老师**：给规则 bot 加真正的防守（安全牌分析、筋牌、对手听牌推测），重跑阶段 3 的监督学习，再 RL。老师强，起点高
3. **两者都做，但先做 2**

我们倾向于 2。因为方向 1 的核心问题——终局信号的信噪比太低——在麻将里是结构性的，不是调参能完全解决的。Suphx 用了两个额外技巧：**全局奖励预测**（用一个单独的网络把终局奖励分配到各个决策点）和**先知教练**（训练时让 critic 看到所有人的手牌，降低价值估计的方差）。这两个都是在直面同一个问题。

## 方法论：怎么写实验记录

这个项目的 PR #3 是一份可以照抄的模板：

1. **改了什么**（表格：文件 → 作用）
2. **结果（如实）**：数字表格，包括置信区间
3. **分析**：为什么是这个结果
4. **评估噪声**：这次实验能分辨多大的差距
5. **下一步候选**：带优先级和理由
6. **建议 review 的地方**：最容易出错的代码位置

标题也写得很直白：「阶段4：PPO 微调框架（第一次尝试：持平老师，未超越）」。

**为什么要把失败写得这么清楚？** 因为三个月后你（或者别人）会想做同样的尝试。一份"我试过，没成，原因是塑形奖励主导"的记录，价值远大于一句"效果不明显"。

机器学习项目里，**负面结果是资产**，前提是你记录了足够的细节让它可复现、可理解。

## 评估的检查清单

拿去用：

- [ ] 目标指标是单一标量吗（不是"胜率高但放炮也多"这种）
- [ ] 控制了位置/顺序效应吗（座位轮转）
- [ ] 用配对设计了吗（同 seed 同对手）
- [ ] 算了置信区间吗
- [ ] 局数够分辨你关心的效应量吗（先估效应量，再反推局数）
- [ ] 基线画在同一张图上了吗
- [ ] 评估用的对手和训练用的对手是不同的吗（防止过拟合特定对手）
- [ ] 记录了随机种子，能复现吗
