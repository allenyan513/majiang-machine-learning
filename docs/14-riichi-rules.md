# 第 14 章 日本立直麻将：规则研究与实现范围

> 这一章还没有对应代码。它是下一个大阶段（重写引擎）的设计输入。

第 13 章的结论是要换一套让防守有分量的规则。麻将 AI 研究界有两个标准：**日本立直麻将**（Suphx、Mortal、NAGA、mjx 全用它，有天凤上千万局公开牌谱）和**中国国标**（IJCAI/Botzone 比赛用，81 番型、8 番起胡，公开数据少）。我们选立直麻将：参考实现多、有外部标尺（可以和开源的 Mortal 对战）、计分天然要求防守。

这一章给熟悉中国麻将、不熟悉日麻的人看。目标是两件事：理解它和推倒胡差在哪，以及为引擎划出实现范围。以天凤（Tenhou）的四人东/南场规则为准。

---

## 1. 一句话概括差异

推倒胡是"谁先凑齐 4 面子 1 对子谁赢，赢固定分"。立直麻将在这上面加了四层东西：

| 层 | 内容 | 对策略的影响 |
|---|---|---|
| **役（yaku）** | 胡牌必须至少带一种"役"（牌型），否则不能胡 | 听牌不等于能胡，要提前规划牌型 |
| **立直（riichi）** | 门清听牌时可以"宣言"，押 1000 点，之后不能换牌；胡了加番 | 公开告诉全桌"我听了"，防守从这一刻开始 |
| **番符计分** | 胡牌得分从 1000 点到 32000 点，差 30 倍 | 大牌值得追，小牌不值得冒险 |
| **点炮全赔** | 点炮者付全额；自摸三家分摊 | 防守是核心技术，弃听是常规操作 |

我们现在引擎里"打得好 = 最快听牌"，在日麻里只对了一半。另一半是"什么时候该放弃"。

## 2. 牌和牌墙

- **136 张**，和我们一样：万筒索各 1–9 × 4，字牌 7 × 4。**没有花牌**。
- **赤宝牌（赤ドラ）**：天凤规则里 5万、5筒、5索各有一张是红色的，胡牌时每张 +1 番。物理上还是 136 张，只是三张 5 有特殊标记。
- **王牌（dead wall）**：牌墙末尾 14 张不摸。里面有：
  - 宝牌指示牌（dora indicator）：开局翻开 1 张，它的**下一张**是宝牌（3万→4万，9万→1万，东→南，北→东，白→发→中→白）。胡牌时手里每张宝牌 +1 番
  - 里宝牌（ura dora）：指示牌下面那张，**只有立直胡牌**的人才能翻，同样每张 +1 番
  - 岭上牌（rinshan）4 张：杠后补牌从这里拿。每杠一次多翻一张宝牌指示牌（杠宝牌）
- 因此一局最多摸 136 − 52 − 14 = **70 张**。

## 3. 一局（一巡）的流程

和我们的状态机基本一致，多了几个动作：

```
发牌 13 张 → 庄家摸第 14 张
循环：
  当前玩家：自摸胡 / 暗杠 / 加杠 / 立直宣言 / 打牌
  打牌后其他人响应：荣和（ron） > 碰、明杠 > 吃（只有下家能吃）
  没人响应 → 下一家摸牌
牌墙摸完 → 流局
```

新增动作：
- **吃（chi）**：只能吃**上家**打的牌，组成顺子。碰/杠谁的都行。
- **立直（riichi）**：条件——门清（没吃碰明杠，暗杠可以）+ 听牌 + 剩余牌墙 ≥ 4 张 + 有 1000 点。宣言后打出的牌横放，押 1000 点到桌上（谁下一个胡拿走）。立直后每次摸牌**只能打摸到的那张**（摸切），除非那张能胡（自摸）或能暗杠且不改变听牌。
- **抢杠（chankan）**：别人加杠的那张牌如果是你的胡牌，可以直接荣和。

## 4. 振听（furiten）——最重要的新概念

**你的听牌里，只要有任何一张出现在你自己的牌河里，你就不能荣和（只能自摸）。**

三种：
1. **舍牌振听**：自己打过的牌在听牌集合里。永久有效直到换听。
2. **同巡振听**：本巡有人打了你能胡的牌而你没胡（无论故意还是没役），到你下次摸牌前不能荣和任何牌。
3. **立直振听**：立直后放过一张能胡的牌，之后整局只能自摸。

对引擎的影响：荣和合法性判断要查自己牌河；对 AI 的影响：听牌选择要避开自己打过的牌。

## 5. 役种

胡牌**必须至少有一种役**。宝牌不算役（只加番）。天凤常用规则允许**食断**（吃碰后的断幺九算役）和**后付**（先吃碰再凑役也行）。

### 5.1 第一版必须实现的役（覆盖 >95% 的实际胡牌）

| 役 | 番（门清/副露） | 说明 |
|---|---|---|
| 立直 | 1 / — | 只有门清能立直 |
| 一发 | 1 / — | 立直后一巡内胡牌，中间没人吃碰杠 |
| 门清自摸 | 1 / — | 没吃碰明杠的自摸 |
| 断幺九 | 1 / 1 | 全部 2–8 的数牌 |
| 役牌 | 1 / 1 | 三元牌（白发中）刻子；自风、场风刻子。每种各 1 番 |
| 平和 | 1 / — | 4 顺子 + 非役牌对子 + 两面听 |
| 一杯口 | 1 / — | 两组相同的顺子（如 223344万） |
| 海底/河底 | 1 / 1 | 摸最后一张自摸 / 胡最后一张打出的牌 |
| 岭上开花 | 1 / 1 | 杠后补的牌自摸 |
| 抢杠 | 1 / 1 | 胡别人加杠的牌 |
| 三色同顺 | 2 / 1 | 万筒索各一组相同数字的顺子 |
| 一气通贯 | 2 / 1 | 同花色 123 456 789 |
| 混全带幺九 | 2 / 1 | 每组都带 1、9 或字牌，有顺子 |
| 七对子 | 2 / — | 七个不同对子（日麻里四张相同**不能**算两对） |
| 对对和 | 2 / 2 | 四刻子 |
| 三暗刻 | 2 / 2 | 三个暗刻（自摸算暗刻） |
| 混一色 | 3 / 2 | 一种花色 + 字牌 |
| 小三元 | 2 / 2 | 两组三元牌刻子 + 第三种做对子 |
| 混老头 | 2 / 2 | 全是幺九字牌 |
| 纯全带幺九 | 3 / 2 | 每组都带 1 或 9，无字牌 |
| 二杯口 | 3 / — | 两个一杯口 |
| 清一色 | 6 / 5 | 一种花色无字牌 |
| 宝牌 / 赤宝牌 / 里宝牌 | 每张 +1 | 不算役 |

### 5.2 役满（13 番，直接 8000 点基本分）

国士无双、四暗刻、大三元、小四喜、大四喜、字一色、清老头、绿一色、九莲宝灯、四杠子、天和（庄家起手胡）、地和（闲家第一巡自摸）。天凤有双倍役满（四暗刻单骑、国士十三面、纯正九莲、大四喜）。

### 5.3 可以后加的

两立直（第一巡立直，2 番）、三杠子、三色同刻、流局满贯（nagashi mangan）、包牌（大三元/大四喜的责任付）。

## 6. 计分

分三步：算番（han）、算符（fu）、查表。

### 6.1 符

- 底符 20
- 门清荣和 +10；自摸 +2（平和自摸除外）
- 面子：明刻 2 / 暗刻 4 / 明杠 8 / 暗杠 16，幺九字牌翻倍
- 对子：役牌对子 +2（连风牌 +4）
- 听牌形：边张、嵌张、单骑 +2；两面、双碰 0
- 七对子固定 25 符；平和荣和固定 30 符，平和自摸 20 符
- 最后向上取整到 10

### 6.2 基本分 → 实际点数

基本分 = 符 × 2^(番+2)，然后封顶：

| 番 | 名称 | 基本分 |
|---|---|---|
| ≤4（且基本分 < 2000） | 按公式 | 符 × 2^(番+2) |
| 5（或 4 番 40 符以上、3 番 70 符以上） | 满贯 | 2000 |
| 6–7 | 跳满 | 3000 |
| 8–10 | 倍满 | 4000 |
| 11–12 | 三倍满 | 6000 |
| 13+ | 役满 | 8000 |

支付（向上取整到 100）：
- **荣和**：点炮者一人付。闲家胡 = 4 × 基本分；庄家胡 = 6 × 基本分
- **自摸**：闲家胡 = 庄家付 2×、另两家各付 1×；庄家胡 = 三家各付 2×

例子：闲家立直 + 门清自摸 + 平和 = 3 番 20 符 → 基本分 640 → 庄家付 1300、闲家各付 700（合计 2700）。闲家一个满贯荣和 = 8000 点，全部由点炮者付。

再加：**本场**（每连庄一次 +300，荣和由点炮者付、自摸三家各 +100）和桌上的**立直棒**（1000/根，胡者拿走）。

### 6.3 流局

- 牌墙摸完：**听牌者分 3000 点**，不听者付。1 人听 → 拿 3000；2 人听 → 各拿 1500；3 人听 → 各拿 1000，不听者付 3000。听牌需要亮牌证明。
- 途中流局（可后加）：九种九牌、四风连打、四家立直、四杠散了、三家和。

## 7. 半庄（一场比赛）

- 东 1–4 局 + 南 1–4 局 = **半庄**，8 局起步；东风战只打东场 4 局。
- 庄家胡牌或流局时听牌 → **连庄**（本场 +1）；否则庄家轮到下家。
- 每人起始 25000 点，**有人跌到 0 以下立即结束**（击飞）。
- 南 4 局庄家第一名时可以选择结束（和了止め）。
- 结算：按名次加 uma（天凤：+20/+10/−10/−20，单位千点）和 oka（返点 30000）。

对 AI 的影响：**局与局之间不独立**——南 4 局落后 8000 点和领先 8000 点该打完全不同的牌。Suphx 的 reward 就是整个半庄的名次，不是单局分数。

## 8. 天凤规则细节（实现时要对齐的）

- 赤宝牌 3 张；食断有；后付有
- 双响（两家同时荣和）允许，三响流局
- 头跳（多家能胡时只有离放炮者最近的能胡）：**不用**，天凤是双响
- 杠宝牌：暗杠立即翻，明杠/加杠打出牌后翻
- 立直后暗杠：只要不改变听牌就允许
- 国士无双可以抢暗杠

## 9. 实现范围切分

### Tier 1：单局完整可玩、AI 能训练（必须）

引擎：
- [ ] 王牌区、宝牌/里宝牌/杠宝牌、赤宝牌标记
- [ ] 吃（限上家）、碰、三种杠、抢杠、岭上牌
- [ ] 立直（宣言、押金、摸切限制、一发判定）
- [ ] 振听三种
- [ ] 役判定：5.1 全表 + 5.2 役满
- [ ] 符计算 + 番符点数表 + 荣和/自摸支付 + 本场/立直棒
- [ ] 荒牌流局听牌费
- [ ] 双响

AI：
- [ ] 向听数加国士无双（七对子改为不允许四张同牌）
- [ ] 规则 bot：立直决策、吃碰决策要考虑役（不能吃碰后没役）、防守用现成危险度模块（终于有用了）
- [ ] 特征加：宝牌、立直状态、自风场风、点数差

### Tier 2：完整半庄（RL 的 reward 才对）

- [ ] 连庄、本场、庄家轮转、击飞、和了止め
- [ ] uma/oka 结算
- [ ] 途中流局五种
- [ ] 包牌、两立直、三杠子、三色同刻、流局满贯

### Tier 3：接入外部生态

- [ ] **天凤牌谱解析**：mjlog 格式 → 我们的引擎回放。有了这个，监督学习可以用**人类高段位数据**而不是规则 bot，这是 Suphx/Mortal 的做法，效果差距是数量级的
- [ ] **mjai 协议**：和 Mortal 对战，得到外部评估标尺
- [ ] 用 mjx 做引擎正确性交叉验证（同一牌谱两边跑，比对结果）

工作量估计：Tier 1 约为现有引擎的 3 倍（役判定和符计算是大头，但都是查表逻辑，测试用例可以从天凤牌谱里大量抽取）；Tier 2 约 0.5 倍；Tier 3 主要是格式解析。
